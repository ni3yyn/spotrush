SpotRush v46.6 — EOS ProductVersion fix

Overlay scripts/networking/EOSOnline.gd onto the SpotRush project root.
Keep the existing EOSG addon, local EOSLocalConfig.gd, and all other project files.

Why: Godot's application/config/version setting has an empty-string default.
ProjectSettings.get_setting(name, "1.0.0") returns the existing empty setting rather
than the fallback argument. EOS_Initialize requires a non-empty ProductVersion, so
EOS returns InvalidParameters (10) before Product/Sandbox/Deployment are consulted.

The fix reads the setting, trims it, and explicitly falls back to "1.0.0" when empty.
It prints only the non-secret product name and version for verification.

After overlaying, restart Godot and click Create Room. Expected output:
[EOS] SDK initialize identity: product='SpotRush', version='1.0.0'
Then the error should progress beyond sdk_initialize.
